# Impact-of-AI-Adoption-on-Workforce-Attrition
AI workforce study analyzing 1,500 employees across 10 industries. Key findings: 41% task displacement, 50% burnout, 65% fear replacement. Backend Engineers most affected. Experimenting AI stage shows 51.4% attrition risk. Consulting/Automotive industries most vulnerable. Data stack: BigQuery, Power BI, Streamlit, Vertex AI.
